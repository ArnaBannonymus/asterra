# Draft “related projects” entry (scikit-learn docs)

This is **not** an scikit-learn core proposal. It is a draft snippet that could be used for a PR adding Asterra to
scikit-learn’s “Related Projects” documentation.

## Proposed entry text

**Asterra** (`asterra`) — Support-aware machine learning for Earth observation. Asterra provides sparse
overlap/group projection operators (e.g., mapping fine-resolution pixels to coarse labels and vice versa),
mixed-resolution feature construction utilities compatible with scikit-learn pipelines, and leakage-aware spatial
cross-validation helpers for EO workflows.

- Source: https://github.com/ArnaBannonymus/asterra
- Docs: https://github.com/ArnaBannonymus/asterra/tree/main/docs
